# 소울매트 배움 노트

요가·명상·AI를 배우고 기록하는 개인 블로그입니다.
Jekyll + GitHub Pages(minima 테마)로 운영됩니다.

- 배포 주소: https://soulairise.github.io/
- 글은 `_posts/` 폴더에 `YYYY-MM-DD-제목.md` 형식으로 추가합니다.

## 로컬에서 미리보기 (선택)

```bash
bundle install
bundle exec jekyll serve
# http://localhost:4000 접속
```

## 새 글 쓰기

`_posts/2026-07-24-example.md` 처럼 파일을 만들고 맨 위에 front matter를 넣습니다.

```
---
layout: post
title: "글 제목"
date: 2026-07-24 16:00:00 +0900
categories: [카테고리]
---
```
